# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/cloverworks-hq/rumpty-cli/security/advisories/new). Include the version (`rumpty --version`), your OS, steps to reproduce, and the impact you expect.

We aim to acknowledge reports within 3 business days and to keep you updated until a fix is released. Once a fix ships, we publish an advisory and credit you unless you ask us not to.

## Supported versions

Security fixes go into the latest release. Upgrade with the install script:

```sh
curl -fsSL https://get.rumptycloud.com | sh
```

## Scope

This policy covers the `rumpty` CLI, `install.sh` and the release artifacts in this repository. Report issues with the Rumpty Cloud service or console the same way; we route them to the right team.
